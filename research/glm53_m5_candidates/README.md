# M5 candidate sources and closed resumed evidence

These are exact frozen copies of the isolated working sources, plus lossless
selected evidence with raw SHA256 and sizes. They are not installed in the
production engine. Builds and runtime selection remain opt-in/OFF. Main and
the original measured helper, comparer, runtime, prompts and weights are unchanged.

`frozen-work` preserves source bytes and the historical sibling layout for
review. Absolute input paths in receipts identify the measured machine. These
copies do not manufacture portable positive bindings: moved/rebuilt binaries
need fresh actual build receipts and numerical validation. Use the original
workspace paths in `source-index.json` to reproduce on this machine; do not
run research workloads concurrently or bypass an admission refusal.

The original CPU16 failed numerical parity. Its tail-corrected helper matched
two complete requests, then failed global swap32MiB during the third. The new
fenced32 helper failed a complete early128-token numerical window and was
cancelled by its verified owner. Neither is a qualified complete profile.

The scalar GPU provider was really built and executed in ordinary CPU graph
fixtures. The first23-case suite failed its128MiB component cap. A distinct
21-case suite excluded the two largest failed/unrun shapes and passed bitexact
comparison, all five repeated output checks,60 publications and266 terminal
commands. Its warm normal graphs were3.77..38.92x slower than CPU10. No full
GLM acceleration follows. The existing raw receipt is retained as a failed
suite; it is never relabelled by the smaller suite.

TensorOps is a separate candidate. Compile-only API failures and corrected
sources are retained. Host compilation, actual shader/pipeline compilation,
bounded component equality/speed and full GLM remain separate proof levels.
The current French report and actual receipts define its latest result.

The reviewed HTTP8 prefix adapter is source-only and gated off by missing
positive full/restore evidence. The unfinished HTTP16 copy is deliberately
excluded. No two useful natural-EOS agents, complete cache gain or600-agent
performance is established. The CPU8 raw archive remains a separate artifact.

The tests here are isolated source/metadata fixtures. They are outside the
original CI test-discovery root to avoid importing historical absolute paths
as portable/production qualification. Original CI controls still run unchanged.

Selected evidence is in evidence-resumed.zip. Extract it at this directory to obtain the indexed evidence/ gzip paths. Every gzip preserves the exact raw SHA256/length in evidence-index.json.
